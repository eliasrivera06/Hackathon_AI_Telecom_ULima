# Carpeta de Imágenes

Coloca aquí los archivos de imagen estáticos del proyecto.

## Ejemplo de uso en un componente React:
```jsx
import movistarLogo from '../../assets/images/movistar-logo.svg';

<img src={movistarLogo} alt="Logo Movistar" className="h-8" />
```
